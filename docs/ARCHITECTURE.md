# Архитектура «Профиля роста»

## Целевой стек
Frontend: React + TypeScript. Backend: FastAPI. Database: PostgreSQL. Экспорт: DOCX.

## Доменная модель
- User — учётная запись и роль.
- EmployeeProfile — профессиональный профиль.
- OrgUnit / ReportingLine — подразделение и отношения руководства.
- Project / ProjectParticipation — проект и участие сотрудника.
- Skill — канонический справочник компетенций.
- EmployeeSkill — связь сотрудника и компетенции, уровень и происхождение.
- SkillEvidence — доказательства из резюме, проекта, СППР или самооценки.
- SkillVerification — подтверждение/отклонение руководителем.
- Certification / CertificationRecommendation — каталог экзаменов 1С и персональные рекомендации.
- DevelopmentGoal — план развития.
- ResumeTemplate / ResumeVersion — шаблон и версии сформированных резюме.
- ImportBatch / ImportRecord — загрузка и аудит данных СППР.

## Инварианты
1. Резюме и рекомендации формируются из профиля, а не из независимых копий данных.
2. Заявленный, обнаруженный и подтверждённый навык имеют разные статусы.
3. Все права доступа проверяются на сервере, включая доступ руководителя к команде.
4. Изменения критичных сущностей аудируются.
5. Экзамен 1С рекомендуется по актуализируемому каталогу и объяснимым правилам.
6. Импорт СППР не изменяет подтверждённые навыки автоматически.
7. Демо-данные отделены от реальных данных.

## Порядок реализации
Сначала сквозной сценарий «профиль → навык → подтверждение → DOCX», затем каталог сертификаций, импорт СППР и ИИ.
