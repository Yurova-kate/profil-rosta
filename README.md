# Профиль роста

Внутренняя платформа профессионального развития специалистов 1С.

## Цель
Единый профиль сотрудника: проектный опыт, навыки, подтверждения руководителя, проектное резюме, рекомендации по сертификациям 1С и планы развития.

## Роли
- **Сотрудник**: собственный профиль, навыки, проекты, резюме и рекомендации.
- **Руководитель**: команда, подтверждение компетенций и профилирование.
- **Администратор**: пользователи, справочники, шаблоны и настройки.

## Принципы
- Один источник данных для всех разделов.
- Нет фиктивных кнопок: действие реализовано от UI до хранилища или отсутствует в интерфейсе.
- Любое изменение бизнес-логики сопровождается тестами.
- Рекомендации ИИ не являются подтверждёнными компетенциями.
- Персональные данные и реальные выгрузки СППР не размещаются в публичном репозитории.

## Состояние
Архитектурный каркас. **Не готов к использованию с реальными персональными данными.**
План реализации: [docs/ROADMAP.md](docs/ROADMAP.md).

## Локальный запуск демонстрационной версии

Требуется Python 3.12+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.server:app --reload
```

Откройте http://127.0.0.1:8000/ и создайте первого администратора. После этого можно добавить руководителя и сотрудника, связать их через поле «Руководитель» и проверить самостоятельную оценку компетенций. Запускать только локально: нет механизмов ограничения попыток входа, защищённого развёртывания и аудита безопасности.

Проверка:

```bash
python -m pytest -q
```

Интерфейс расположен в `web/index.html`, API в `app/main.py`. Данные сохраняются в локальном SQLite, не в GitHub. Браузерное тестирование и production hardening ещё не выполнены.

## Справочник компетенций (API)

Новый модуль `app/competencies.py` подключён через `app.server`. Администратор добавляет канонические компетенции; сотрудник назначает уровень; уровень указывается сотрудником самостоятельно, без подтверждения руководителя. Проверки находятся в `tests/test_competencies.py`.

**Ограничение текущей версии:** пользовательский экран выбора компетенций, алиасы, миграция ранее введённых свободных навыков, интеграция с DOCX и рекомендациями ещё не реализованы. Существующие навыки сохранены. Новые API не следует считать законченным пользовательским сценарием.

### Обновление от 04.11.2026
Подтверждение навыков руководителем исключено из интерфейса и API. Начальный справочник 1С заполняется при запуске. Ранее введённые навыки сохранены без автоматического сопоставления. Исторические поля подтверждения в SQLite пока оставлены для обратной совместимости. Тесты API требуют запуска в CI или локально.
